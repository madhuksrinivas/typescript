# TypeScript With React

This folder is a small React + TypeScript tutorial app.

It covers the basics you use most often in React projects:

- Components
- Props
- Optional and reusable prop types
- `children` with `ReactNode`
- `useState` with strings, numbers, arrays, and objects
- Event types like `FormEvent` and `ChangeEvent`
- Forms
- Lists with `map`
- Conditional rendering
- `useEffect`
- Union types for loading states
- `Omit` for reusing object types

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build Check

```bash
npm run build
```

## File Guide

Start with `src/App.tsx`. It now only connects state, handlers, and page layout.

The examples are split by topic:

- `src/types.ts`: shared TypeScript types like `Lesson`, `CourseLevel`, `NewLesson`, and `LoadState`.
- `src/data/lessons.ts`: sample lesson data typed with `Lesson[]`.
- `src/components/Panel.tsx`: reusable component with typed `children`.
- `src/components/Badge.tsx`: simple component typed with props.
- `src/components/LessonItem.tsx`: typed props and button click handler.
- `src/components/LessonList.tsx`: rendering typed arrays with `map`.
- `src/components/NewLessonForm.tsx`: typed `useState`, form submit events, and input change events.
- `src/components/LessonsPanel.tsx`: passing props between parent and child components.
- `src/components/NewLessonPanel.tsx`: using `Omit` through the `NewLesson` type.
- `src/components/ProgressPanel.tsx`: conditional rendering.
- `src/components/LoadStatePanel.tsx`: discriminated union state.

## Config Files

### `package.json`

`package.json` describes the React project. It tells npm what commands are available and which packages the app needs.

Important parts in this project:

- `scripts.dev`: starts the Vite development server.
- `scripts.build`: runs TypeScript checking and creates the production build.
- `scripts.preview`: previews the production build locally.
- `dependencies`: packages needed by the app, such as React, React DOM, Vite, and TypeScript.
- `devDependencies`: packages mostly used for development, such as React type definitions.
- `type: "module"`: tells Node.js to treat JavaScript files as ES modules, so `import` and `export` syntax works normally.

You usually configure `package.json` when you want to add a new library, add a command, or change how the project starts/builds.

### `tsconfig.json`

`tsconfig.json` controls how TypeScript checks this project.

Important options in this project:

- `target: "ES2020"`: TypeScript outputs modern JavaScript features supported by modern browsers.
- `lib: ["DOM", "DOM.Iterable", "ES2020"]`: gives TypeScript browser types like `document`, `window`, and HTML events.
- `strict: true`: enables stronger type checking so mistakes are caught early.
- `module: "ESNext"`: keeps modern `import` and `export` syntax for Vite to bundle.
- `moduleResolution: "Bundler"`: matches how Vite resolves imports.
- `jsx: "react-jsx"`: allows JSX in `.tsx` files without importing React in every component file.
- `noEmit: true`: TypeScript checks types but does not create JavaScript files. Vite handles the actual build output.
- `include: ["src"]`: TypeScript only checks files inside the `src` folder.

You usually configure `tsconfig.json` when you want stricter checking, browser or Node types, path aliases, JSX settings, or different build behavior.

### `tsconfig.tsbuildinfo`

`tsconfig.tsbuildinfo` is generated automatically by TypeScript when the build uses project build mode, such as `tsc -b`.

It stores build cache information so TypeScript can make future builds faster. You normally do not edit this file by hand.

If it is deleted, TypeScript can recreate it during the next build.
